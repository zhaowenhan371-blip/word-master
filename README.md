# 单词大师

大学英语四级 / 六级词汇练习，单文件 HTML 应用，内置双单词本、单词卡等级标注、发音、例句和软件更新。

- 四级单词本：2072 词
- 六级单词本：2454 词（含 1169 个四六级重叠词）
- 六级独有词：1285 词

## 在线版

GitHub Pages 发布后，可从 `https://zhaowenhan371-blip.github.io/word-master/` 打开。

## 更新

应用内「设置 → 软件更新」读取 `update.json`。发布新版时替换 `index.html`，并把 `update.json` 的 `version` 改高。
